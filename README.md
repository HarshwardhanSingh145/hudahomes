## 🚀 Running Locally

To preview the website locally, run any static web server from the project root:

```bash
# Using Python 3
python3 -m http.server 8080

# Or using Node / npx
npx serve .
```

Open [http://localhost:8080](http://localhost:8080) in your browser.
